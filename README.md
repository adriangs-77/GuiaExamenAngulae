# Guía de examen · Angular 22

Guía de estudio en un único archivo HTML autocontenido (sin CDN ni dependencias):
**[`guia-examen-angular.html`](guia-examen-angular.html)**

## Contenido

1. Instalación del entorno (Node.js, npm, Angular CLI y compatibilidad con Angular 22)
2. Crear y ejecutar el proyecto (`ng new`, `ng serve`, `--open`, `--port`)
3. Componentes (generación, estructura, standalone, uso de otros componentes)
4. Binding (interpolación, property, event y two-way binding)
5. Signals (`signal`, `set`, `update`, `computed`, `effect`)
6. Estructuras de control (`@if`, `@for`, `ngIf`, `ngFor`)
7. Routing (rutas, parámetros, guards, lazy loading)
8. Comunicación entre componentes (`input()`, `output()`, `@Input`, `@Output`)
9. NgModule y su situación actual
10. Formularios reactivos (FormGroup, validaciones, FormBuilder, FormArray)
11. Servicios e inyección de dependencias (`inject()`, ámbitos, HttpClient, WebSocket)
12. Angular Material
13. Chuleta de comandos, equivalencias y errores frecuentes
14. Autoexamen de 35 preguntas con respuestas
15. Glosario y repaso final

## Uso

Abre el archivo en cualquier navegador moderno. Incluye:

- Índice lateral con seguimiento de la sección activa y **buscador** (atajo `/`).
- Tema claro/oscuro e **impresión / exportación a PDF**.
- Botón de copiar en cada bloque de código y resaltado de sintaxis sin librerías.
